# VELIX v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build VELIX from the empty repo as a small Telegram video extraction bot with Cloudflare orchestration and an isolated extractor service.

**Architecture:** Cloudflare Worker handles Telegram webhook updates, validation, job state, format selection and delivery. A separate extractor runtime performs heavy media extraction/downloads. Shared TypeScript contracts keep the two sides stable.

**Tech Stack:** TypeScript, Node.js workspaces, Cloudflare Workers/Wrangler, KV, Queues, Telegram Bot API, Python extractor service, pytest.

**Spec:** `docs/design/velix-v1.md`

## Global Constraints
- Public, technically extractable media only.
- No DRM/private/paywall/access-control bypass.
- No per-user quota in v1.
- Heavy extraction never runs in the Worker.
- Secrets are never committed.
- Reject localhost, loopback, link-local, private-network and metadata-service destinations.
- Bound every external call with timeouts and size limits.
- Use tests before implementation for deterministic logic.

### Task 1 — Workspace foundation
- **Files:** `package.json`, `tsconfig.json`, `.gitignore`, CI workflow, README, `tests/smoke/package.test.ts`.
- **Test first:** add a Vitest smoke test importing `packages/shared/src/index.ts`; run it and confirm failure.
- **Implement:** npm workspaces for `apps/*` and `packages/*`, Vitest, TypeScript scripts (`test`, `typecheck`, `build`, `lint`), shared package entrypoint.
- **Verify:** `npm test -- --run tests/smoke/package.test.ts`; `npm run typecheck`.
- **Commit:** `chore: initialize VELIX workspace`.

### Task 2 — Shared contracts and URL safety
- **Files:** `packages/shared/src/types.ts`, `errors.ts`, `url-safety.ts`, `job.ts`, `index.ts`; tests under `tests/shared/`.
- **Interfaces:** `MediaFormat`, `SubtitleTrack`, `ExtractionResult`, `Job`, `JobState`, `validatePublicUrl(raw)`, `selectVideoFormat(formats,maxBytes)`.
- **Test first:** valid HTTP(S), malformed/scheme/credential/private-host rejection; format selection by resolution and size; legal job transitions.
- **Implement:** pure deterministic functions and contracts.
- **Verify:** focused Vitest, then `npm run typecheck`.
- **Commit:** `feat: add shared contracts and safety core`.

### Task 3 — Telegram primitives
- **Files:** `packages/bot/src/telegram-client.ts`, `update-parser.ts`, `messages.ts`, tests under `tests/bot/`.
- **Interfaces:** `parseIncomingUrl(update)`, `TelegramClient.sendMessage`, `editMessageText`, `sendVideo`, `sendAudio`, `sendDocument`.
- **Test first:** `/start`, plain URLs, captions containing URLs, malformed/non-text updates.
- **Implement:** typed Telegram API wrapper with fetch timeout and short user messages.
- **Verify:** focused tests.
- **Commit:** `feat: add Telegram bot primitives`.

### Task 4 — Isolated extractor
- **Files:** `apps/extractor/src/server.py`, `models.py`, `security.py`, `extract.py`, `requirements.txt`, `Dockerfile`, Python tests.
- **Interfaces:** `POST /health`; authenticated `POST /extract` returning the normalized extraction contract.
- **Test first:** signature validation, unsafe URL rejection, normalized result mapping.
- **Implement:** small HTTP service around a generic extraction engine; subprocess timeout, temporary-directory isolation, size limits, sanitized errors.
- **Verify:** `pytest apps/extractor/tests -q`; `docker build -t velix-extractor ./apps/extractor`.
- **Commit:** `feat: add isolated media extractor`.

### Task 5 — Worker orchestration and jobs
- **Files:** `apps/worker/src/index.ts`, `env.ts`, `extractor-client.ts`, `job-store.ts`, routes, `wrangler.toml`; worker tests.
- **Interfaces:** `GET /health`, `POST /telegram/webhook`, `ExtractorClient.extract(request)`, KV-backed `JobStore`.
- **Test first:** health, webhook-secret rejection, `/start`, invalid URL, extractor failure, successful extraction metadata.
- **Implement:** Cloudflare Worker routes, KV state, idempotency, HMAC/shared-secret extractor calls, short errors.
- **Verify:** focused tests, `npm run build`, `npm run typecheck`.
- **Commit:** `feat: build Cloudflare Telegram worker`.

### Task 6 — Format UI and delivery
- **Files:** `packages/bot/src/format-selector.ts`, `keyboards.ts`, `delivery.ts`; worker Telegram route; delivery tests.
- **Interfaces:** `buildFormatKeyboard(formats)`, `handleFormatCallback(callback)`, `deliverJob(job, selectedFormat)`.
- **Test first:** quality buttons, callback parsing, automatic best-format fallback, upload failure mapping.
- **Implement:** inline quality selection; video/audio delivery; subtitles when available; direct-link fallback only when safe and practical.
- **Verify:** focused tests.
- **Commit:** `feat: add media selection and delivery`.

### Task 7 — Deployment
- **Files:** `apps/worker/wrangler.toml`, `.github/workflows/deploy.yml`, `scripts/set-webhook.mjs`, README.
- **Implement:** Worker deployment with `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`; KV/Queue bindings; health check; Telegram webhook registration using secrets.
- **Verify:** GitHub Actions green, live `/health` HTTP 200, webhook accepted by Telegram.
- **Commit:** `ci: automate VELIX deployment`.

### Task 8 — Release verification
- **Files:** `tests/e2e/contract.test.ts`, `docs/runbook.md`, README.
- **Implement tests:** Worker/extractor JSON contract with mocked extractor; error mapping; no-secret scan.
- **Verify:** `npm test`, `npm run typecheck`, `pytest apps/extractor/tests -q`, container build, live health, Telegram `/start`, and one public supported video URL end-to-end.
- **Commit:** `test: verify VELIX v1 release path`.
